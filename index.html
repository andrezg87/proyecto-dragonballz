¿Algo no carga?

Abre el menú desde el servidor del curso. En la terminal, dentro de la carpeta del repositorio:
npm install        # solo la primera vez
npm run verificar  # comprueba que tu computador está listo
npm run servir     # y entra a http://localhost:5500
