¿Cómo funciona la web? 10 min

Cuando escribes una dirección en el navegador, este le pide a un servidor unos archivos. El navegador recibe texto (HTML, CSS, JS) y lo convierte en la página que ves.

🦴
HTMLEl esqueleto: qué hay en la página (títulos, textos, imágenes).
🎨
CSSLa ropa y el maquillaje: cómo se ve (colores, tamaños, posición).
⚡
JavaScriptLos músculos: qué hace (interacción, lógica). Fuera de esta clase.
Herramientas Solo necesitas un editor de código (recomendado: VS Code) y un navegador. Crea un archivo index.html, ábrelo con doble clic y listo. Tip: la extensión Live Server recarga la página sola al guardar.

HTML: estructura base 0:10

HTML se escribe con etiquetas. Casi todas abren y cierran: <p>texto</p>. Algunas no tienen cierre (se llaman vacías): <img>, <br>, <input>.

<!DOCTYPE html>              <!-- Le dice al navegador: esto es HTML5 -->
<html lang="es">             <!-- Raíz del documento, idioma español -->
  <head>                     <!-- Información invisible (metadatos) -->
    <meta charset="UTF-8">   <!-- Para que se vean bien las tildes y la ñ -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi primera página</title>   <!-- Texto de la pestaña -->
    <link rel="stylesheet" href="estilos.css">
  </head>
  <body>                     <!-- Todo lo que se VE va aquí -->
    <h1>¡Hola mundo!</h1>
  </body>
</html>
Atajo en VS Code Escribe ! y presiona Tab o Enter: se genera toda la estructura automáticamente.

Etiquetas de texto

EtiquetaPara qué sirve
<h1> … <h6>Títulos, de más importante a menos. Un solo h1 por página.
<p>Párrafo.
<strong> / <em>Importancia (negrita) / énfasis (cursiva).
<br>Salto de línea.
<hr>Línea separadora.
<span> / <div>Contenedores genéricos: en línea / en bloque.
<!-- -->Comentario (no se ve en la página).
✏️ Pruébalo
Bloque vs. en línea Los elementos de bloque (h1, p, div) ocupan todo el ancho y empiezan en una línea nueva. Los elementos en línea (span, a, strong) solo ocupan lo que mide su contenido.

Atributos, enlaces e imágenes

Los atributos dan información extra a una etiqueta. Van en la etiqueta de apertura: nombre="valor".

AtributoEjemploQué hace
href<a href="https://...">Destino de un enlace.
target="_blank"<a ... target="_blank">Abre en pestaña nueva.
src<img src="foto.jpg">Ruta del archivo.
alt<img alt="Un gato">Texto alternativo (accesibilidad y SEO). ¡Siempre!
id<section id="contacto">Nombre único en la página.
class<p class="destacado">Grupo reutilizable (para CSS).
✏️ Pruébalo
Rutas foto.jpg = misma carpeta · img/foto.jpg = dentro de la carpeta img · ../foto.jpg = una carpeta arriba · https://... = ruta absoluta en internet.

Listas y tablas

✏️ Pruébalo

ul = unordered list, ol = ordered list, li = list item. En tablas: tr = fila, th = celda de encabezado, td = celda de dato.

HTML semántico

En vez de llenar todo de <div>, usamos etiquetas que describen su contenido. Ayuda a Google, a lectores de pantalla y a quien lee tu código.

<header>   Cabecera: logo, título        </header>
<nav>      Menú de navegación             </nav>
<main>     Contenido principal (uno solo)
  <section>  Una sección temática         </section>
  <article>  Contenido independiente (un post, una noticia) </article>
  <aside>    Contenido secundario (barra lateral) </aside>
</main>
<footer>   Pie de página: contacto, copyright </footer>

CSS: ¿cómo se conecta? 1:00

Antes y después: la misma página, sin CSS y con CSS

Esta es una página hecha solo con HTML. Funciona, pero se ve como un documento de los años 90. Presiona ✨ Agregar CSS y mira cómo cambia, sin tocar una sola etiqueta del HTML.

✏️ Página sin CSS
La idea clave El HTML dice qué hay (un encabezado, un menú, tres productos). El CSS solo dice cómo se ve. Por eso podemos cambiar todo el diseño sin tocar el contenido. Después de agregar el CSS, prueba a cambiar los colores #3b2a20 o #c8865a por otros.

Anatomía de una regla CSS

CSS = Cascading Style Sheets. Una regla CSS tiene esta forma:

selector {
  propiedad: valor;   /* cada declaración termina en ; */
  otra-propiedad: valor;
}

/* Ejemplo */
h1 {
  color: tomato;
  font-size: 40px;
}

Hay 3 formas de agregar CSS:

FormaEjemplo¿Cuándo?
Externo ✅<link rel="stylesheet" href="estilos.css"> en el headSiempre que puedas. Separa estructura y estilo.
Interno<style> h1 { color: red; } </style> en el headPruebas rápidas, una sola página.
En línea ⚠️<h1 style="color: red">Casi nunca. Difícil de mantener.

Cascada y especificidad

Si dos reglas apuntan al mismo elemento, ¿cuál gana?

  1. Especificidad: style="" > #id > .clase / :hover > etiqueta.
  2. Si empatan, gana la que está más abajo en el código (por eso se llama "cascada").
  3. Herencia: propiedades de texto (color, font-family) pasan de padres a hijos.
✏️ ¿De qué color será el texto? Adivina antes de mirar
Evita !important rompe la cascada. Úsalo solo como último recurso.

El modelo de caja el concepto más importante

Todo elemento en HTML es una caja con 4 capas:

margin
border
padding
contenido
width × height
  • content: el texto o imagen.
  • padding: espacio interno (entre contenido y borde). Toma el color de fondo.
  • border: el borde.
  • margin: espacio externo (separa de otras cajas). Siempre transparente.
✏️ Juega con los números
¿Por qué box-sizing: border-box? Sin él, width: 220px + padding + border = la caja mide más de 220px. Con border-box, el ancho que escribes es el ancho final. Mucho más intuitivo.

Flexbox: acomodar elementos

Para poner cosas en fila o columna, alinearlas y repartir espacio. Se aplica al padre (contenedor), y afecta a sus hijos directos.

Propiedad (en el padre)Valores comunesQué hace
display: flex—Activa Flexbox.
flex-directionrow · columnDirección del eje principal.
justify-contentflex-start · center · space-between · space-aroundAlineación en el eje principal.
align-itemsstretch · center · flex-start · flex-endAlineación en el eje cruzado.
gap16pxEspacio entre hijos.
flex-wrapwrapPermite saltar de línea.
✏️ Cambia justify-content y align-items
El truco más famoso Centrar algo perfectamente: display: flex; justify-content: center; align-items: center; en el padre. 🎯
Para practicar jugando: Flexbox Froggy.

Responsive: que se vea bien en el celular

Con media queries aplicamos estilos solo cuando la pantalla cumple una condición. Achica la ventana del navegador para probar.

✏️ Cambia el 500px por 800px
No olvides Sin <meta name="viewport" content="width=device-width, initial-scale=1.0"> en el head, el celular "finge" ser una pantalla grande y tus media queries no funcionan.

Errores comunes

SíntomaCausa probable

El CSS no hace nadaRuta del href mal escrita, o falta rel="stylesheet".
Una regla no se aplicaFalta un ; o una }, o hay otra regla más específica.

Tu mejor amigo: DevTools Clic derecho → Inspeccionar (o F12). Ahí ves el HTML, qué reglas CSS se aplican, cuáles están tachadas (perdieron la cascada) y el modelo de caja de cada elemento. Puedes editar en vivo.
