# 01 · Clase de HTML y CSS

**Qué es:** la guía interactiva de la primera clase. Cada ejemplo con código es editable: cambias el código de la izquierda y ves el resultado a la derecha en tiempo real.

**Cómo abrirla:**

- Con el servidor del curso: `npm run servir` (desde la raíz del repositorio) y entra a <http://localhost:5500/01-clase-html-css/clase-html-css.html>
- O con doble clic sobre [`clase-html-css.html`](clase-html-css.html).

**Qué contiene:** cómo funciona la web, estructura de HTML, etiquetas, enlaces e imágenes, listas, tablas, formularios, selectores y cascada de CSS, modelo de caja, Flexbox, responsive y un proyecto final (tarjeta de perfil).

**Cómo usarla para repasar**

1. Lee la sección y **antes de ejecutar**, predice qué va a pasar.
2. Cambia algo en el editor y comprueba si acertaste.
3. Haz los retos del final y marca los que logres.

Necesitas internet solo para las fuentes y algunas imágenes de ejemplo.

## Laboratorio de CSS en movimiento

En [`laboratorio-css/`](laboratorio-css/) hay una página de ejemplo que muestra lo que se puede lograr con CSS: gradientes, animaciones, transiciones y efectos de luz.

- Ábrela con `npm run servir` en <http://localhost:5500/01-clase-html-css/laboratorio-css/index.html> o con doble clic sobre `laboratorio-css/index.html`.
- Todo el estilo está en [`andres.css`](laboratorio-css/andres.css) y la estructura en [`index.html`](laboratorio-css/index.html).

**Cómo sacarle provecho**

1. Abre `andres.css` en VS Code y cambia los colores de la sección `:root` (variables como `--purple` o `--cyan`). Guarda y recarga: ¿qué cambia?
2. Busca una animación o transición (`@keyframes`, `transition`) y cambia su duración. ¿Qué efecto tiene?
3. Escoge un efecto que te guste y explica con tus palabras cómo está hecho, mirando el selector y las propiedades que usa.

Esta página usa la misma idea del curso: el HTML dice **qué hay**, el CSS dice **cómo se ve**.
